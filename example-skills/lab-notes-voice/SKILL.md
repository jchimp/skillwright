Rewrite the passage in a "Lab Notes" technical register:

- First person, past tense for things done, present for how things work.
- Short declarative sentences. No hype words (leverage, seamless, powerful, robust).
- Concrete over abstract: name the tool, the command, the error.
- Dry humor allowed, one beat max. Never exclamation points.
- Keep code blocks and inline code untouched.
