# Word list

Words to cut. If one is load-bearing, rewrite the sentence around what it was hiding.

| Cut | Use instead |
| --- | --- |
| leverage | use |
| utilize | use |
| seamless, effortless | (say what actually happens) |
| powerful, robust | (name the specific capability) |
| delve into, dive into | (just say the thing) |
| in order to | to |
| it's worth noting that | (delete, keep the note) |
| a variety of, a number of | (give the number) |
| best-in-class, cutting-edge | (delete) |

Phrasings to avoid:

- "It's not just X, it's Y." — pick one.
- Three-item lists where two items would do.
- Rhetorical questions as section openers.
- Closing paragraphs that summarize what the reader just read.

Keep: specific tool names, version numbers, error strings, commands, file paths.
